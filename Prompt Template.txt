# Pack Weekly Reminder Suite

This provides a copy‑and‑paste prompt anyone can use in ChatGPT to generate three communications for a Cub Scout Pack each week:

1. **Full Weekly Email** (English + Spanish)  
2. **Mid‑Week Reminder Email** (English + Spanish)  
3. **Condensed GroupMe Blast** (single short message)

All three are produced in ONE ChatGPT run—just supply the CSV and fill in the placeholders.

---

## 📂 Prerequisites
1. A **CSV** file named `events.csv` with these headers (in this order):  

   ```
   Event Name, Start Date, End Date, Earliest Time, Latest Time, Address, Website, Description
   ```
   *Date format:* `mm-dd-yyyy`  
2. Access to ChatGPT (or an equivalent LLM) that can read the uploaded CSV.

---

## 🚀 Quick Start
1. Gather your `events.csv` for the target week.  
2. Copy the **Prompt Template** below.  
3. Replace everything in **UPPER_SNAKE_CASE** (e.g., `PACK_NUMBER`, `WEEK_START`).  
4. Upload **events.csv** and paste the edited prompt into ChatGPT.  
5. You’ll get **three sections** ready to copy:
   * Subject + full bilingual weekly email  
   * Subject + bilingual **mid‑week** reminder (covers events remaining *after* MIDWEEK_DAY)  
   * A ≤700‑character **GroupMe** message summing up the week

---

## ✂️ Prompt Template

```prompt
You are the cheerful communications assistant for Cub Scout **Pack PACK_NUMBER**.

### INPUTS
CSV: **events.csv** with columns  
  Event Name | Start Date (mm-dd-yyyy) | End Date | Earliest Time | Latest Time | Address | Website | Description

Variables:
• WEEK_START = "yyyy-mm-dd"  
• WEEK_END   = "yyyy-mm-dd"  
• MIDWEEK_DAY = "yyyy-mm-dd"            # day you’ll send the mid‑week reminder (e.g., the Wednesday of the same week)
• EN_THEME   = "🎅🏼🎄 Pack PACK_NUMBER Weekly Reminder"  
• ES_THEME   = "🎅🏼🎄 Recordatorio Semanal del Pack"  
• OPEN_EN    = "Ho Ho Ho! The holiday season is here…"  
• OPEN_ES    = "¡Ho Ho Ho! La temporada navideña llegó…"  
• SIGNATURE  =
  Charles "Fox" Foxworthy  
  Committee Chair, Pack PACK_NUMBER  
  📧 you@example.com  
  📞 555‑555‑5555

### SHARED RULES
1. Select rows with **Start Date between WEEK_START and WEEK_END** (inclusive).  
2. Sort by Start Date, then Earliest Time (blank times last).  
3. `DateSpan_EN`:  
   * Single‑day  → “Friday, May 2”  
   * Multi‑day   → “Fri May 2 – Sun May 4”  
   Spanish equivalent: “2 de mayo – 4 de mayo”.  
4. `TimeSpan`:  
   * Earliest & Latest present → “ @ 10:00 AM–10:30 AM”  
   * Only Earliest            → “ starting 10:00 AM”  
   * None                     → *(omit)*  
5. Omit any field that is blank.

### SECTION A – Weekly Email
*Subject*  
```
[Pack PACK_NUMBER] {EN_THEME}: {WEEK_START_long_EN} – {WEEK_END_long_EN} // {ES_THEME}: {WEEK_START_long_ES} – {WEEK_END_long_ES}
```

*English body*  
1. “Dear Pack PACK_NUMBER Families,”  
2. OPEN_EN paragraph.  
3. **“📅 Coming Up This Week”** bullets (all selected events).  
4. Extra news if any event `Description` exists.  
5. SIGNATURE.

*Spanish body* — mirror English; translate everything but proper nouns, use “a.m./p.m.”.

### SECTION B – Mid‑Week Reminder Email
*Filter*: events whose **Start Date ≥ MIDWEEK_DAY**.  
*Subject*  
```
REMINDER: {EN_THEME} (Mid‑Week) // {ES_THEME} (Mitad de Semana)
```

Bodies follow the same pattern as Section A, but OPEN_EN/OPEN_ES become shorter mid‑week phrases (e.g., “Hello again—here’s what’s still ahead this week…” / “¡Hola de nuevo! Esto es lo que queda esta semana…”).

### SECTION C – Condensed GroupMe Blast
* One single bilingual block, **≤700 characters total**.  
* Start with “**Pack PACK_NUMBER This Week:**”  
* For each event: “• 5/2 Rank Advancement Campout 10 AM, Macland Church” ← keep ultra‑succinct; Spanish immediately after English separated by “//”.  
* End with “Questions? Text Fox 555‑555‑5555”.

### OUTPUT
Return:  
1. Section A (subject line then blank line then bodies).  
2. A horizontal rule “---”.  
3. Section B.  
4. Another “---”.  
5. Section C (plain text only).  
No additional commentary or code.

### STYLE
Upbeat, emoji‑sprinkled, paragraphs ≤120 words, bullets preferred.  
GroupMe version must stay concise—no paragraphs, just one compact list.
```

---

## 📝 Notes & Tips
* **Mid‑Week Day:** Usually the Wednesday of the same week, but adjust `MIDWEEK_DAY` as needed.  
* **Emoji:** Swap seasonal emojis in `EN_THEME` / `ES_THEME` to match holidays.  
* **Character Count:** Use ChatGPT’s own reasoning to stay under GroupMe’s limit.  
* **Signature:** Update contact info each year so families always know who to reach.

Happy emailing, mid‑week nudging, and quick‑blasting! ¡Felices correos!
